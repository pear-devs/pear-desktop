! =====================================================================
! YTMusic Privacy Shield
! Additional filter rules for a dedicated YouTube Music client
! Assumes the client's built-in Lite anti-ad layer is ALWAYS active:
!
!   Property traps:
!     playerResponse.adPlacements = undefined
!     ytInitialPlayerResponse.playerAds = undefined
!     ytInitialPlayerResponse.adPlacements = undefined
!     ytInitialPlayerResponse.adSlots = undefined
!
!   JSON cleanup:
!     playerAds
!     adPlacements
!     adSlots
!     playerResponse.playerAds
!     playerResponse.adPlacements
!     playerResponse.adSlots
!     ytInitialPlayerResponse.playerAds
!     ytInitialPlayerResponse.adPlacements
!     ytInitialPlayerResponse.adSlots
!     entries[].command.reelWatchEndpoint.adClientParams.isAd
!     reelWatchSequenceResponse.entries[].command.reelWatchEndpoint.adClientParams.isAd
!
! Therefore this file deliberately contains NO duplicate property traps,
! json-prune rules, or response-rewrite logic.
! =====================================================================

! PROFILE: BALANCED
! Recommended default.
!
! Blocks:
! - advertising infrastructure
! - ad measurement / impressions
! - obvious YouTube tracking pixels
! - QoE/ad telemetry that should not be required for user features
! - generic Google Analytics / Tag Manager calls
! - cosmetic ad/promoted UI
! - common tracking URL parameters
!
! Preserves:
! - youtubei/v1/log_event
! - api/stats/watchtime
! - api/stats/playback
! - api/stats/delayplay
! - api/stats/streamingstats
!
! Intent: history, recommendations, Recap, resume/progress and normal
! playback behavior should remain intact.
! =====================================================================
